## 📖 Sobre o projeto

O **LunarisRP** é um servidor de Minecraft focado em Roleplay, construção de narrativas e exploração de um universo próprio.

Este repositório contém o código-fonte do site oficial do projeto, desenvolvido para apresentar sua identidade, mitologia e comunidade.

O site funciona como um portal de entrada para o universo Lunaris, reunindo informações importantes para jogadores atuais e novos visitantes.

## 🛠️ Tecnologias utilizadas

O projeto utiliza tecnologias do ecossistema Java e desenvolvimento web:

- **Java 21** — linguagem principal.
- **Spring Boot** — estrutura da aplicação.
- **Spring Web** — gerenciamento de rotas HTTP.
- **Thymeleaf** — renderização de páginas HTML.
- **HTML5** — estrutura das páginas.
- **CSS3** — estilização e responsividade.
- **JavaScript** — interatividade.
- **Maven** — gerenciamento de dependências e build.
- **Docker** — empacotamento e execução.
- **Render** — hospedagem da aplicação.


## 🎨 Identidade visual

A identidade visual do LunarisRP é inspirada em fantasia medieval, mitologia cósmica e fenômenos sobrenaturais.

A interface busca transmitir a atmosfera misteriosa do universo do servidor por meio de:

- Paleta de cores escuras e elementos luminosos.
- Referências visuais a manuscritos e registros antigos.
- Elementos celestiais e simbologia mística.
- Tipografia inspirada em universos de fantasia.
- Layout adaptável para diferentes dispositivos.
